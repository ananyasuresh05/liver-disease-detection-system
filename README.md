# Liver Disease Detection & Medical Report System

This repository contains my individual contribution to our final-year undergraduate team project:  
**An AI-Based Hospital Diagnostic System**.

## Module Overview
This module focuses on **Liver Disease Detection** using machine learning and generates a detailed, medical-style diagnostic report.

## Features
- Machine Learning-based liver disease prediction (Logistic Regression)
- Probability-based risk stratification:
  - Low Risk
  - Moderate Risk
  - High Risk
  - Severe Risk
- Clinically formatted medical report
- Interpretation of abnormal biomarkers
- Flask-based web application
- Designed for integration into a larger hospital dashboard

## Technologies Used
- Python
- Flask
- scikit-learn
- Pandas, NumPy
- Joblib
- HTML/CSS

## How to Run
1. Create a Python environment (Python 3.9 recommended)
2. Install dependencies:
pip install -r requirements.txt
3. Run the application:
python app.py
4. Open browser:
http://127.0.0.1:5001


## Project Context
This module is part of a **team project consisting of four diagnostic systems**:
- Liver Disease (my contribution)
- Heart Disease
- Kidney Disease
- Diabetes Detection

Each module runs independently and integrates via a central hospital dashboard.
